Test build only. Not approved for production kitchen operations or the A/B pilot.

Adds Developer options, About device and Android settings shortcuts under Settings. Manufacturer restrictions may prevent direct access.

Package: com.ebbinnovation.kitchendisplay
Version: 0.3.3 (7)
Signing: Android debug certificate. Existing installations require a matching signing certificate. Do not uninstall or clear data to bypass a signing mismatch.

Known blockers: successive additions may duplicate previous items; ready status may affect multiple batches; cancellation may leave additions active. Compatibility validation remains incomplete.

This repository distributes compiled APK files only. No source, saved API keys, restaurant configuration or order data is included. Android APKs contain compiled application logic and can be reverse engineered.

Downloading does not install or update the restaurant TV automatically.
